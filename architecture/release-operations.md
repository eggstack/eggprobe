# Release and Operational Qualification

## 1. Release model

* **Ordinary release = qualified archives + checksums + manual install** (`docs/operator.md`, `README.md`): archive contains `eggprobe` binary + license + README metadata; verify against `SHA256SUMS.txt`; move into trusted directory manually. Source builds need Rust ≥1.89. No auto-download/replacement script. Non-goals: no auto-update daemon, no telemetry, no package-manager matrix before direct artifacts stable, no local producer framework (Eggpack) or updater engine (Eggup) copies, no self-update requirement before first release.
* **ADR-0002 boundary** (`plans/adrs/ADR-0002-release-producer-consumer-ownership.md`, `plans/registry.md`): Eggpack owns target/artifact identity, package/archive construction, final manifest/digest/size, bootstrap installers, generated release CI/staging/publication. Eggprobe owns release/version selection policy, supported-target claims, whether self-update is exposed. Eggup owns acquisition/verification, staging/locking/commit/rollback/recovery, receipts/lifecycle. Future producer work SHALL use Eggpack; future in-place update SHALL use Eggup; manifest→deployment translation is the optional interop seam. `eggup-dist` producer authority retired to Eggpack.
* **Deferred integrations; first release unblocked:** historical M003 superseded by ADR-0002 + M003a (Eggpack producer adoption, blocked on closure-backed interfaces) + M003b (optional Eggup self-update, blocked on interop closure + product decision). First standalone archive release SHALL NOT wait for M003a/M003b. Real blocker is own hosted artifact evidence: C001 conditionally closed (needs intentional release tag + successful hosted packaging run with artifact/hash/smoke evidence; repo currently untagged), C002 closed, M004 blocked only on M002/C001 evidence.

## 2. Qualification matrix, MSRV, verification

* **Targets** (`docs/operator.md`, `.github/workflows/release.yml`): linux x86_64/aarch64, macos x86_64/arm64, windows x86_64. Host-native smoke on all except linux-aarch64 (cross via `houseabsolute/actions-rust-cross`, `file`-inspected; build-qualified until native SBC smoke recorded). Invariants: don't advertise unsupported targets; distinguish aarch64 build vs native runtime; smoke validates machine output too; release version ≠ schema version.
* **MSRV/toolchain:** 1.89.0 (`README.md`, `Cargo.toml: rust-version 1.89`, `rust-toolchain.toml: 1.89.0 + rustfmt,clippy`); edition 2021, resolver 3, version 0.1.0; lints `unsafe_code=forbid`, `clippy all/pedantic=warn`, workspace-applied to both crates.
* **Verification** (`README.md`): `cargo fmt --check`, `cargo check --workspace --all-targets --all-features --locked`, `cargo clippy … -- -D warnings`, `cargo test --workspace --all-features --locked`, `cargo +1.89.0 check …`, `cargo tree --locked`, `cargo audit`. CI (`ci.yml`): quality matrix (ubuntu/macos/windows) fmt+clippy+test; MSRV check; `rustsec/audit-check` with `GITHUB_TOKEN`. Release (`release.yml`): `workflow_dispatch` with `version` input validated against `^v\d+\.\d+\.\d+$` (the `v*` tag-push trigger lives in `release-skeleton.yml`, not `release.yml`), tag/source/version proof (`git describe`, `cargo metadata`, `release-identity.txt`), locked release builds, native smoke (`--version` + `run --ndjson` loopback `0.3` plan asserting `schema_version/status/route` via `jq`), archive staging (`LICENSE+README+identity`), `.tar.gz`/`.zip` + `.sha256`, integrity + checksum verify, `upload-artifact` (`if-no-files-found: error`). `release-skeleton.yml`: build/smoke skeleton, no publish. C001 fixed cross-arch smoke, per-archive checksums, `version`-input (not `GITHUB_REF_NAME`), tag/version consistency.

## 3. Operator surface (`docs/operator.md`)

* **Install/verify:** obtain archive + `SHA256SUMS.txt` → verify → move manually. M004 adds: install/archive instructions, target table, verification record, schema-fixture compatibility vs release binary, dep/security evidence, no unresolved ≥medium blocker, update instructions only if M003b closed.
* **Quick-start:** `dns/tcp/tls/http/check … --json`; finite deadlines, no Ctrl+C retry; 4xx/5xx are observations (assertions classify without erasing); `run plan.json` single report, `run - --ndjson` one record per plan; `--concurrency` bounds with input-order output; `--fail-fast` stops admitting after first negative while awaiting started; 4 MiB/256-plan bounds; stderr logs, stdout machine-only under `--json`/`--ndjson`; `schemas/*-0.3.json` active, `0.1/0.2` historical, binary rejects old, Rust types authoritative, additive-only-when-optional-and-redaction-safe; `--via`/plan `route` for Eggress, `{"kind":"eggress"}` reports, `eggress(<redacted>)` debug/human, no env-proxy fallback.
* **Troubleshooting:** DNS = client scope (not remote hop); `connection_refused/timeout/tls/protocol` structured outcomes; HTTP phase timings `unavailable` when observer lacks them; H1/H2 only (no H3 selector, no QUIC dialer); exits `0/1/2/3/130`; no self-update command (not blocking); no bootstrap/generated CI (Eggpack-owned, adopt when stable).
* **`compare`:** direct-first + routed-second, matching target/probes; separate distributions; nearest-rank `ceil(p*N/100)` on successful timings only.

## 6. Review Checklist / Risks

* First-release gate: choose `vX.Y.Z` matching package version → hosted 5-target build + `release-identity.txt` + per-archive `.sha256` + integrity/checksum verify + 4 native smokes + aarch64 inspection → promote M002/C001 → execute M004 (artifacts, fixture compat, target table with SBC distinction, verification record, `cargo tree`/`audit`, operator docs, no ≥medium blocker) → document manual-install-only, no self-update, Eggpack/Eggup future-optional → confirm ADR-0002 planning conformance (no producer/consumer logic copies).
* Risks: Windows networking may need platform qualification; aarch64 cross ≠ native runtime evidence; early Eggpack adoption binds to unclosed APIs (adopt closure-backed slices only); Eggup self-update needs product justification + stable adapter; standalone machinery must not grow into a second Eggpack; size/throughput claims need measurement without harming diagnostics; MSRV + `forbid(unsafe)` + strict Clippy must stay green tri-OS; qualification needs artifact/workflow evidence, not code inspection (don't mistake M002 conditional closure for operational qualification).
